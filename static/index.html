Free Video Studio

1. Project and media

2. Transcribe with Whisper (free, local)

Whisper runs on your own machine. Captions are added to the timeline JSON on the right.

3. Free media (Openverse)

Only CC0 / CC-BY / CC-BY-SA items. Credits are saved to credits.json.

4. Sound effects (earshot)

Needs the earshot CLI installed. Set EARSHOT_CMD if its command differs.

5. Edit by prompt (AI)

Uses Ollama on this machine by default (free). Set AI_PROVIDER=gemini and GEMINI_API_KEY to use Google's free tier. The result goes into the timeline below for you to review before you render.

6. Generate clip (Higgsfield, optional, paid)

seconds

Needs your own Higgsfield key (HIGGSFIELD_KEY_ID and HIGGSFIELD_KEY_SECRET). This is a paid service that charges your account. Generation can take several minutes. The app cannot show the cost before you run it.

5. Timeline (JSON) and render

Renders with Hyperframes. First run downloads its browser and may take a few minutes.
